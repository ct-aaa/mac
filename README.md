# 32 输入 Q1.15 乘加器

本项目实现一个面向 32 项向量点积的定点乘加核。数据通路包含 8 个并行 MAC 单元，每个输入周期接收 8 对 16 bit 有符号 Q1.15 数据，连续 4 个有效周期完成 32 对数据输入；随后通过三级流水平衡加法树生成 40 bit 有符号点积结果。

## 设计规范

- 设计语言：□ Verilog-2001　☑ SystemVerilog　□ VHDL
- 编码风格：可综合、单时钟同步设计、避免锁存器
- 复位方式：低有效异步复位
- 命名规范：模块名使用小写加下划线，信号名表达实际功能
- 注释要求：每个模块头部包含功能说明、作者、日期和版本；主要流水阶段及功能模块前包含中文说明

```text
│  └─ mac32_8lane_top.sv    # 32 项点积顶层

│  └─ tb_mac32_8lane_top.sv # 自检测试平台

```

## 数据与接口

- 输入格式：16 bit 有符号 Q1.15
- 单拍输入：8 对操作数，共 256 bit
- 单次点积：4 个有效输入拍，共 32 对操作数
- 输出格式：40 bit 有符号累加结果，保留乘积的 30 位小数
- 输入握手：`start` 标记首拍，`in_valid` 与 `in_ready` 同时为高时接收数据
- 输出握手：`result_valid` 为高时，`result` 有效

## 仿真

在项目根目录执行：

```powershell
.\sim\scripts\run_vsim_gui.ps1
```

脚本会重新编译源码和测试平台、运行全部自检用例并打开波形。测试结束后 ModelSim GUI 保持打开，便于查看时序。

当前回归包含 137 个点积用例。无输入气泡时，首拍至结果有效相隔 7 个周期，最短任务启动间隔为 8 个周期。

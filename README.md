# 32 输入 Verilog-2001 乘加器

本项目实现一个 32 项有符号点积核。数据通路包含 8 个并行 MAC 单元，每个有效输入周期接收 8 对 16 bit 数据，连续 4 个有效周期完成 32 对数据输入，随后通过三级流水平衡加法树生成 40 bit 有符号结果。

## 设计规范

- 设计语言：Verilog-2001
- 编码风格：可综合、单时钟同步设计、避免锁存器
- 复位方式：低有效异步复位
- RTL 循环：不使用过程式 `for`；8 个 MAC 使用 `generate for` 结构展开
- 输入格式：16 bit 有符号数
- 输出格式：40 bit 有符号乘积累加结果，不额外执行 Q1.15 缩放

## 项目结构

```text
.
├─ src/
│  ├─ mac_lane_q15.v          # 单路两级流水 MAC
│  ├─ mac32_8lane_ctrl.v      # 四拍输入事务控制器
│  ├─ reduce_tree8_q15.v      # 8 路三级流水平衡加法树
│  ├─ mac32_8lane_top.v       # 32 项点积计算核心
│  └─ mac_top.v               # FPGA 三端口自运行 LED 展示顶层
├─ tb/
│  ├─ tb_mac32_8lane_top.v    # 正常随机激励测试顶层
│  └─ tb_mac_top_fpga.v       # FPGA LED 展示测试顶层
├─ tb_mac_top_asic.v          # 用户提供的参考源码，不计入正式测试

```

## 计算核心接口

`mac32_8lane_top` 每拍通过 `a_in[127:0]` 和 `b_in[127:0]` 接收 8 对操作数。位段 `[16*i +: 16]` 对应 lane `i`。

- `start`：标记事务首拍
- `in_valid`：当前输入有效
- `in_ready`：计算核心可以接收当前输入
- `busy`：计算核心正在处理事务
- `result_valid`：40 bit `result` 当前有效

无输入气泡时，首拍至 `result_valid` 相隔 7 个周期，最短事务启动间隔为 8 个周期。

## FPGA 展示顶层

`mac_top` 只有 `clk`、`rst_n` 和 `led` 三个外部端口。复位释放后，它自动按四拍向计算核心送入两组相同的 `1..32` 数据，并计算：

```text
1*1 + 2*2 + ... + 32*32 = 11440
```

结果等于参数 `TARGET`（默认 `40'd11440`）时，LED 置高并保持到下一次复位。参数 `EN_GAP` 默认为 0；设为非 0 时会在相邻有效输入拍之间插入一个空拍。当前硬件数据通路支持默认配置 `DATA_W=16`、`ACC_W=40`、`N=32`。

## 仿真

工程包含两套正式的 Verilog-2001 测试顶层：

1. `tb_mac32_8lane_top.v`：正常随机激励测试顶层。它直接验证 `mac32_8lane_top` 计算核心，包含 6 个确定性边界用例、128 个随机用例和 3 个带输入气泡的随机用例，共 137 个点积测试，同时检查结果、固定延迟和事务启动间隔。
2. `tb_mac_top_fpga.v`：FPGA LED 展示测试顶层。它验证三端口 `mac_top` 复位后自动计算 `1*1+2*2+...+32*32=11440`，并检查结果正确后 LED 是否持续保持点亮。


脚本以 Verilog 模式编译 `src/` 和 `tb/` 下的正式源码，并默认启动正常随机激励顶层 `tb_mac32_8lane_top`。需要验证 FPGA 展示功能时，在 Vivado 或其他 Verilog-2001 仿真器中将 `tb_mac_top_fpga` 设为仿真顶层。
